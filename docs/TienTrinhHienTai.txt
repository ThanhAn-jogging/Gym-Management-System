Để bắt đầu "chiến đấu" và tự tay xây dựng giao diện xịn xò như bản mẫu, bạn cần chuẩn bị một "bộ súng ống" đầy đủ cho thư mục **FRONTEND**. Nhìn vào sơ đồ thư mục của bạn, có vẻ bạn đã có khung nhưng chưa có các thư viện bổ trợ[cite: 1].

Dưới đây là các bước cài đặt cụ thể:

### 1. Kiểm tra "Nền móng" (Node.js)
Trước tiên, máy bạn phải có **Node.js** (thứ cho phép bạn chạy các lệnh `npm`). Bạn mở Terminal ngay tại thư mục `FRONTEND` và gõ:
```bash
node -v
npm -v
```
Nếu nó hiện ra phiên bản (ví dụ: `v20.x.x`) là ổn. Nếu chưa, bạn cần tải Node.js bản LTS về cài nhé.

---

### 2. Cài đặt các "Vũ khí" hạng nặng
Bạn hãy chạy các lệnh sau trong Terminal để cài đặt các thư viện cần thiết nhất:

*   **Tailwind CSS (Để làm giao diện đẹp):** Đây là thứ quan trọng nhất để bạn tạo ra màu đen sâu và xanh Electric Blue mà không cần viết hàng nghìn dòng CSS thủ công[cite: 1].
    ```bash
    npm install -D tailwindcss postcss autoprefixer
    npx tailwindcss init -p
    ```
*   **React Router (Để chuyển trang):** Để khi bạn bấm vào "Hội viên" trên Sidebar, nó thực sự chuyển sang trang Hội viên mà không bị load lại cả trang web[cite: 1].
    ```bash
    npm install react-router-dom
    ```
*   **Axios (Để "nối ống" với Backend):** Thư viện này giúp bạn gọi API từ Spring Boot (`localhost:8080`) cực kỳ chuyên nghiệp và dễ quản lý hơn hàm `fetch` mặc định[cite: 1].
    ```bash
    npm install axios
    ```
*   **Lucide React (Để lấy Icon):** Để có những icon tối giản, sắc nét giống như trong Figma[cite: 1].
    ```bash
    npm install lucide-react
    ```

---

### 3. Cấu trúc lại một chút "Kho chứa đồ"
Trong ảnh của bạn, có một lỗi chính tả nhỏ có thể gây rắc rối sau này khi bạn gọi đường dẫn ảnh[cite: 1]:
*   Bạn hãy đổi tên thư mục `assests` thành **`assets`** (bỏ bớt một chữ 's').



### 4. Thiết lập "Màu sơn" (Tailwind Config)
Để có màu xanh **Electric Blue** và các tông màu tối chuẩn bài, bạn mở file `tailwind.config.js` vừa sinh ra và thêm mã màu vào phần `theme`:
```javascript
/** @type {import('tailwindcss').Config} */
export default {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  darkMode: 'class', // Để sau này bạn làm nút gạt Light/Dark mode
  theme: {
    extend: {
      colors: {
        'electricBlue': '#007BFF',
        'darkBg': '#000000',
        'darkCard': '#121212',
      },
    },
  },
  plugins: [],
}
```
